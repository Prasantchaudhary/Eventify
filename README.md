# Eventify – A Web‑Based Event Management System

Eventify is a full‑stack event management platform designed to streamline college event creation, registration, and administration. Built as a final‑year project, it provides an intuitive interface for students and organizers while ensuring secure and efficient event handling.

---

## 🚀 Features

* **User Roles:** Supports Organizer and Attendee roles.
* **Event Management:** Create, update, delete, and manage events.
* **Event Registration:** Students can register for events directly through the platform.
* **Dashboard:** Role‑specific dashboards for event insights and management.
* **Validation & Error Handling:** Robust server‑side checks for data consistency.
* **Modular Architecture:** Separated frontend and backend for cleaner structure and easier maintenance.
